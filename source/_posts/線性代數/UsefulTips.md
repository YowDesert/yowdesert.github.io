# 甚麼時候沒有反矩陣？

- **方陣有反矩陣 ⇔ det 不為 0 ⇔ rank = n ⇔ 行列線性獨立 ⇔ 𝐴𝑥=0 ， Ax=0 只有零解 ⇔ 0 不是EigenValue**

- 解釋一下 : 
    - det 不能是 0:
        因為 $A A^{-1} = I$，$det(A) * det(A^{-1}) = det(I) = 1$ ，所以det(A)不能是`0`
    - 齊次方程有非零解 : 
        如果 $Ax = 0$ 有 $x != 0$的解，那A就不可逆
        因為如果有反矩陣，左右乘$A^{-1}$會得到 Ix = 0
        => 不可能還有非0解
    - 0 不是EigenValue
        因為 Av = λv 且 v != 0
        如果 λ = 0 則Av`有非0解`，因為v不為0，但Av卻是0。
